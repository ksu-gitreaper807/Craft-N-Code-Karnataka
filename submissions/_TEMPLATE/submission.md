## Project summary

BoardRoom is an interactive whiteboard for programming teachers. It turns handwritten or typed C++ and Python lessons into reviewed, runnable programs, then shows compiler errors and program output alongside the lesson so teachers can explain concepts without switching to a separate IDE.

## Short answers

**1. What made you choose this problem?**

Programming is often taught by moving between a board, a classroom compiler, and slides. That breaks the flow of an explanation and makes it harder to connect an error on screen to the line a teacher just wrote. We wanted to make the whiteboard itself a place where code can be explained, checked, and run while preserving the teacher's original work.

**2. Who is it for, and how would they use it in a normal week?**

BoardRoom is for programming teachers, instructors, and students demonstrating code in a classroom or workshop. A teacher writes or types a C++ or Python example, selects its region, and can have Gemini transcribe the handwriting for review before running it. They can try input cases, show output and diagnostics, browse teaching data-structure libraries, and save dated lesson snapshots for later use.

**3. If you had another month, what would you build next?**

We would improve handwriting recognition with a representative classroom handwriting benchmark and make recognition speed and accuracy easier to evaluate. We would expand reusable lesson and test-case libraries, improve collaboration and classroom sharing, and strengthen the reliability of hosted code execution and snapshot history. We would also test the product with teachers and use their feedback to refine the lesson workflow.
